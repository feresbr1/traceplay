# Changelog

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-19

### Added

- Tracer API: arrays (bars and cells), grids, graphs (circle, force, layered, manual layouts), binary and n-ary trees, variables, narration (`t.say`), code-line sync (`t.line`), `t.batch`, and 11 tones.
- Player: interpolated motion, code panel, variables panel, captions, play/pause/scrub/speed, keyboard control, light and dark themes.
- GIF export in the browser, with narration in every frame.
- CLI: `render` (self-contained HTML or JSON), `check` (quality report), `init` (4 templates), `docs`. Works in ES-module and CommonJS projects.
- Agent skill (`npx skills add feresbr1/traceplay`).
- Website: gallery of 11 real traces, example pages, and a playground with a sandboxed worker and share links.
