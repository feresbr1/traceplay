A picture of code running beats a paragraph explaining it. So I built a way to get one from any function.

traceplay turns an algorithm into an interactive, step-by-step animation, and every frame comes from actually running the code. You keep your real implementation and add a few calls that say what to show, like a.swap(i, j), g.mark('B', 'visited') or t.say('…'). The animation can't drift from the code.

What you get:
▶️ arrays, grids, graphs, trees and variables, with smooth motion
▶️ the source beside the animation, with the current line highlighted and narration under every step
▶️ play, pause, scrub, speed control and keyboard shortcuts
▶️ sharing as a link, a GIF exported in the browser, or one offline HTML file

Because the API is small and deterministic, AI coding agents are good at writing traces. With the agent skill installed, "explain this function" becomes a playable animation.

Useful for teaching, onboarding, code review and technical writing. Open source, MIT, no account, no server.
